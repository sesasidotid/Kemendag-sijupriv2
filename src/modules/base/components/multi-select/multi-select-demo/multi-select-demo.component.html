How to Use
Features:
  • Click the select box to open the dropdown
  • Use the search bar to filter options
  • Check/uncheck items to select/deselect them
  • Click the X on badges to remove individual selections
  • Click the X button next to the arrow to clear all selections
  • Click outside the dropdown to close it
Component Returns:

The component returns an array of IDs of selected options. The parent component receives only the IDs and can access the full data by filtering the original options array.

Integration:
  • Works with [(ngModel)] for two-way binding
  • Works with formControlName in reactive forms
  • Emits (selectionChange) event with array of IDs
  • Supports form validation
