Petunjuk Pengumpulan Portfolio

  1. Siapkan jawaban portfolio Anda dalam bentuk file PDF.
  2. Klik tombol Pilih File pada setiap pertanyaan untuk mengunggah jawaban. Anda dapat mengunggah beberapa file PDF sekaligus untuk setiap pertanyaan.
  3. Setelah mengunggah file, klik tombol Simpan Jawaban untuk menyimpan jawaban pertanyaan tersebut.
  4. Catatan: Jika Anda mengunggah beberapa file PDF, file-file tersebut akan digabungkan menjadi satu file oleh sistem setelah diproses oleh server (membutuhkan beberapa saat).
  5. Pastikan semua pertanyaan sudah tersimpan (ditandai dengan badge hijau "Tersimpan").
  6. Jika seluruh pertanyaan telah dijawab dan disimpan, informasi “Semua tugas telah disimpan” akan muncul >di bagian atas halaman.

Tips: Anda dapat memperbarui jawaban yang sudah tersimpan dengan mengunggah file baru dan klik Simpan Jawaban lagi.
