Petunjuk Pengumpulan Portfolio

  1. Siapkan jawaban portfolio Anda dalam bentuk file PDF.
  2. Klik tombol Pilih File pada setiap pertanyaan untuk mengunggah jawaban.
  3. Pastikan semua pertanyaan sudah diunggah (tidak boleh ada yang kosong).
  4. Jika semua sudah selesai, klik tombol Kirim Portfolio.

Jika mengalami kesulitan, silakan hubungi panitia ujian.
