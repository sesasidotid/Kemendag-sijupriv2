Unduh Soal Ujian

Klik tombol di bawah untuk mengunduh soal ujian.

Petunjuk Pengerjaan

  1. Klik tombol Unduh Soal.
  2. Masukkan Secret Key yang diberikan oleh panitia, lalu klik Unduh.
  3. Soal akan otomatis terunduh ke perangkat Anda.
  4. Buka file soal dan kerjakan jawabannya.
  5. Setelah selesai, simpan jawaban dalam bentuk PDF.
  6. Pilih file jawaban (PDF), lalu klik Kirim.

Jika mengalami kesulitan, silakan hubungi panitia ujian.
