Petunjuk Pengerjaan

  2. Popup soal akan muncul di layar Anda.
  3. Baca soal dan kerjakan jawabannya.
  4. Setelah selesai, simpan jawaban dalam bentuk PDF.
  5. Pilih file jawaban (PDF), lalu klik Kirim.

Jika mengalami kesulitan, silakan hubungi panitia ujian.
